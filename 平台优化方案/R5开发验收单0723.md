### 多行业编辑交互确认

```text
所属行业  [编辑]
  一级行业（可多选） [搜索________________]
  □ 制造与工业   ☑ 商贸与消费   ☑ 信息技术与通信

  二级行业（可多选） [范围：已选一级行业 v] [搜索________________]
  ☑ 食品              商贸与消费
  ☑ 软件与服务        信息技术与通信
  □ 电子元器件        信息技术与通信

  [保存] [取消]
```

- 取消某一级行业会一起移除其下已选二级行业；二级行业被选择时，其所属一级行业自动保留。
- 允许只选择一级行业；L2 始终与自己的 L1 成对保存，避免多选后失去父级语义。

### Prompt 发布记录

已在「设置 → Prompt 版本管理」为 `business_update_extractor` 新建 `v0.9.0` 并设为默认版本。正文已明确：

1. 标的行业输出 `industry_pairs_json: [{"l1":"...","l2":"..."}]`，可多条；不得再输出 `industry_primary/industry_secondary` 宽表字段。
2. 所在地输出 `location_province/location_city/location_district`；不得再输出总部/注册地旧字段。
3. 有明确“已售出、已成交、已停售、暂停出售、不再出售”证据时，输出 `lifecycle_status: sold/off_market`；同时可输出 `is_for_sale: no`。
4. “业务与产品·其他”不得复制 `business_summary`；产业链/行业地位补充并入业务与产品，出售意愿/风险补充并入交易属性与出售诉求。

这是运行时 Prompt 配置，按仓库规则不以 SQL seed 迁移交付。`render-preview` 已成功解析 `context_json`、`raw_text` 两个变量。
