## 三、请你验收的场景（按顺序，约 30 分钟）

登录管理员账号（`deploy/.env` 里的 `ADMIN_USERNAME / ADMIN_PASSWORD`）。

### 1. 设置页（2 分钟）
- 打开「设置」：只有「AI 节点」「模型与搜索」两个 tab，**没有「数据字典」**。
- 「AI 节点」里打开「标的新建解析」的 Prompt 版本：默认版本是 v0.12.0，正文里没有 `{{ industry_l1_list }}`；
  点「渲染预览」，变量面板里没有行业字典变量。

### 2. 标的列表（5 分钟）
- 列表有「业务标签」列（原「行业」列位置），大部分标的显示 3~5 个顿号分隔的词，如「汽车零部件、商用车车架」。
- 筛选栏「业务标签」下拉：列出库里真实存在的标签及计数（如 医疗器械 3、汽车零部件 2）；选一个，列表只剩命中的标的；清空筛选恢复。
- 搜索框下拉字段选「业务标签」，输入「医疗」→ 命中带医疗类标签的标的；选「全部字段」也能命中。
- **预期不会出现**：行业两级级联下拉、「一级行业 / 二级行业」字样。

### 3. 新建标的（5 分钟）
- 「新建标的」弹窗里是「业务标签」输入框（占位文案「细分赛道或产品品类，多个用顿号分隔」）。
  - 填「汽车零部件、商用车车架」+ 名称 → 创建 → 列表该行的业务标签列显示这两个词。
  - 留空 + 粘贴一段业务材料 → 创建后等解析完成（AI 处理列变「已完成」）→ 业务标签由解析写出，应是细分赛道 / 产品品类的词，**不是**「制造业 / 能源」这种大类，也不是公司名。

### 4. 标的信息页（5 分钟）
- 「业务与产品」组里第一行是「业务标签」，点铅笔进入编辑：一个文本框，顿号分隔；改一个标签保存 → 页面刷新后显示新值，「更新记录」里出现「业务标签」一条、来源「手动编辑」。
- 「业务标签」**没有「筛」角标**（它不是筛选维，这是设计）。
- 对一个标的点「AI 调研」，等它跑完：若调研补出了业务标签，会以「待确认」或直接写入出现（空字段自动采纳，已有值且不同则待确认）；待确认卡片上「修改并采纳」是一个顿号分隔的文本框。

### 5. 看板（1 分钟）
- 「标的业务标签 top」面板有条形图；脚注形如「共 94 个标的；榜外另有 N 个标签；K 个未填业务标签」。
  **没有**「二级行业字典存在同义词未合并」那句。

### 6. 外部 Agent / MCP（5 分钟，用 wegent 那把 `wegent-agent-ecs` 的 key）
- 调 `targets_scan`：每条有「业务标签」（自由词）、「业务摘要」「主要产品」；老数据若没标签则**没有「业务标签」这个键**（不是空字符串）。
- 调 `target_get`：档案里「业务标签」在「地区」前面；没有「行业」键。
- 调 `targets_filter`（例如 `{"conditions": {"min_revenue_yuan": 100000000}}`）：`returned` 里每条有 `business_tags`（有标签时）；**没有** `industry`。
- `tools/list`：`targets_filter` 的 `conditions` 属性与改前完全一致（要求地区、上市状态、营收 / 净利 / PE / 市值 / 估值），**没有**标签条件——这是判决 B，不是漏了。

### 7. 全局搜索（1 分钟）
- 顶部搜索「医疗」：标的结果的副标题里是标签串（如「医疗器械 · 浙江省杭州市」），不再是「医药与健康 / 医疗器械」。
